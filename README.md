## Descripción del Proyecto

Este **examen práctico** consiste en la **réplica fiel** del **flujo de entrada principal** de un aplicativo web para la **DIAN (Dirección de Impuestos y Aduanas Nacionales)**, basado en el **diseño entregado por el equipo de UI/UX**.

El objetivo es:

- **Replicar con precisión** el diseño propuesto  
- Usar **solo HTML5 y CSS3 nativos**  
- Garantizar **100% responsividad**  
- Mostrar **historias de usuario** y **casos de estudio** para personas naturales y jurídicas  

> **Resultado:** Una página estática, limpia, profesional y **pixel-perfect** con el diseño original.

---

## Características Implementadas

| Característica | Detalle |
|---------------|--------|
| **HTML Semántico** | Estructura clara con `<header>`, `<main>`, `<section>`, `<footer>` |
| **CSS Moderno** | Flexbox, Grid, variables, transiciones |
| **Responsivo** | Breakpoints para móvil, tablet y escritorio |
| **Tipografía Oficial** | Fuentes similares a la DIAN |
| **Colores y Espaciado** | Réplica exacta del diseño UI/UX |

| Tecnología | Uso |

| **HTML5** | Estructura semántica y accesible |
